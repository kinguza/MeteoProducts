Data Update Console

Trigger the incremental data update from here. The server pulls only the new days since the last successful run and merges them into the existing aggregated files — no manual shell access required.

1 · Authenticate

Enter the ADMIN_TOKEN that was set on the API server. It's stored in this browser only (localStorage) and sent as the X-Admin-Token header on every request.

3 · Trigger update

This runs bash all_agro_dataproces.sh update on the server. It probes NOAA and CHIRPS for new data, downloads only what's new, and merges it into the existing aggregations. Typical cost: a few hundred MB and <1 minute on a normal day.

Tip: leave this page open — live progress appears in the log below. After the run, the explorer's dropdowns will pick up the new data automatically on the next request.
